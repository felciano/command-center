COMMAND CENTER / ON DEMAND

Your dashboard. On your terms.

Open Command Center when you need it. Your new-tab page stays yours.

Open a new dashboard in

Changing the launch mode affects the next new dashboard. Close an existing dashboard first to use the new mode.

Keyboard shortcut

The suggested shortcut is Command + Shift + Y on Mac, or Ctrl + Shift + Y on Windows/Linux.

Set or change it at chrome://extensions/shortcuts. The shortcut is scoped to Chrome by default.

Something not working?

Open chrome://extensions, find Command Center - On Demand, and check for errors. After rebuilding, click Reload on that extension card. Do not remove the extension to update it.

This launcher does not configure service accounts, API keys, or Google OAuth. Those remain the dashboard's own settings.
